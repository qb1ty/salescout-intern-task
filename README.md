# 🚀 SaleScout Intern Task — Прайс-бот для Kaspi.kz

Мини-версия прайс-бота, который автоматически управляет ценами продавцов, анализируя конкурентов и удерживая первую позицию без ухода в минус.

## ✨ Что реализовано

1. **Core-логика (`src/pricing.ts`)**: Чистая функция `calculatePrice`, которая строго следует правилам демпинга, игнорирует товары не в наличии и соблюдает лимиты `minPrice` / `maxPrice`.
2. **REST API (Express)**: Эндпоинт `POST /reprice`. Реализована **глубокая валидация** входящего массива с помощью кастомных Type Guards (возвращает статус 400 при некорректных данных).
3. **Frontend (React + Vite + Tailwind CSS)**: Чистый и адаптивный UI. Данные запрашиваются через кастомный хук, реализовано наглядное сравнение «было/стало» с цветовой индикацией статусов.
4. **Тесты (Vitest)**: Написаны тесты для бизнес-логики, включая проверку всех граничных условий (Edge cases).

## 🛠 Требования к окружению

*   **Node.js**: >= 20.x
*   **npm**: >= 10.x
*   ⚠️ **ВАЖНО:** Убедитесь, что **порт 3000** на вашем компьютере свободен (на нем запускается бэкенд). Фронтенд по умолчанию запустится на порту `5173`.

## 📦 Установка

Поскольку проект состоит из бэкенда и фронтенда, зависимости нужно установить в обеих директориях.

1. Склонируйте репозиторий и перейдите в него:
```bash
git clone <ссылка-на-ваш-репозиторий>
cd salescout-intern-task
```

2. Установите зависимости для **бэкенда** (корневая папка):
```bash
npm install
```

3. Установите зависимости для **фронтенда**:
```bash
cd frontend
npm install
```

---

## 🚀 Запуск приложения

Для полноценной работы вам понадобится открыть **два терминала**.

**Терминал 1: Запуск API (Бэкенд)**
Убедитесь, что находитесь в корне проекта (`salescout-intern-task`), и выполните:
```bash
npm run dev:server
```
*Сервер запустится на http://localhost:3000*

**Терминал 2: Запуск интерфейса (Фронтенд)**
Перейдите в папку фронтенда и запустите Vite:
```bash
cd frontend
npm run dev
```
*Откройте в браузере ссылку, которую выдаст Vite (обычно http://localhost:5173)*

## 📡 Пример работы с API

Вы можете протестировать логику в обход интерфейса. Отправьте `POST` запрос с массивом товаров на эндпоинт `/reprice`:

```bash
curl -X POST http://localhost:3000/reprice \
-H "Content-Type: application/json" \
-d '[{
  "sku": "IPH15-128-BLK",
  "name": "Apple iPhone 15 128Gb черный",
  "myPrice": 389990,
  "minPrice": 370000,
  "maxPrice": 420000,
  "step": 10,
  "competitors": [
    { "seller": "TechnoMarket", "price": 384990, "inStock": true }
  ]
}]'
```
